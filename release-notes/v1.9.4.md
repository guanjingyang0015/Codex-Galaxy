# Codex Galaxy 1.9.4

## 多中转站管理

- 延续 1.9.3 的多中转站管理、账号快照保护和 GitHub 发布记录显示能力。

## 桌面聊天窗口连续性

- 账号切换后优先使用 Codex 官方支持的 `codex://threads/<线程ID>` 深链，直接回到原来的桌面聊天窗口。
- 深链不可用时才退回 `codex resume` CLI，不再默认只打开终端。
- 切换前仍会保存并保护本地线程、SQLite 索引和最新账号状态。

## 验证

- 增加桌面线程深链调用回归断言。
