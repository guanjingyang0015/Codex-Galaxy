# Codex Galaxy 3.1.0

- 保持现有首页、账号卡片、API 检测按钮和操作流程不变；用户仍然点击一次“API 检测”，后台自动完成全部测试并只展示一个 100 分总分。
- GPT 模型会自动增加三次行为指纹测试，只使用随应用发布的 GPT 候选库，不包含 Claude。用户无需复制提示词、创建测试聊天或粘贴数字回答。
- 详细报告新增 GPT 行为指纹候选、候选库概率和有效查询数。行为候选与请求模型不一致时，指纹项为 0/15 且总分最高 79；指纹请求不可用时不计该项并沿用原有模型核对权重，避免因输出截断误判。
- 排名服务采用同一套服务端重算规则，并保存脱敏 API 路径、指纹候选、概率、有效样本数和分项分数；API Key、完整 prompt、原始数字回答和聊天正文不会提交或保存。
- GPT 指纹评分器和候选库来自 MIT 许可的 ModelTrace，版权与许可文件随安装包保留。README、中英文应用内教程、文档和回归测试已同步更新。
- 保留 gracefulTerminate 的 catch 兜底、本地日志、model_catalog_json、Windows sandbox 和模型目录兼容性检查。
