# Codex Galaxy 3.4.0

## 中转协议自动适配

- API 配置新增“自动适配”：OpenAI Responses、OpenAI Chat Completions、Anthropic Claude Messages、Gemini 原生 `generateContent` 统一由本机网关交给 Codex；已有直连配置保持不变。
- 支持普通文本、流式结束事件、命名空间/自定义工具、并行工具调用与结果回传。Gemini thought signature 只留在内存，并通过 stdin 交接给受控后台助手，不写状态文件或日志。
- 只有明确的端点不存在/不支持时才切换协议。鉴权、限流、5xx、超时、模型不存在不会触发换协议重试。
- 不支持的远程压缩、服务端托管搜索、特殊内容与结构化输出约束明确报错，不静默丢弃；自动适配不向 Codex 宣称上游具有托管搜索能力。
- 模型列表或适配器补充的模型名不视为上游已声明的型号；评分与排行榜继续使用真实声明证据。
- 同步更新 README、中英文教程和文档；本地日志、`gracefulTerminate` + `catch`、`model_catalog_json`、Windows sandbox 和跨账号本机项目连续性继续保留。
