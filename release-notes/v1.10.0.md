# Codex Galaxy 1.10.0

## Phased usage guide

- Reorganized the in-app tutorial into four independent stages: first account setup, daily account switching, failure recovery, and feature overview.
- Daily switching now has separate API → official and official → API instructions, with a shared pre-switch checklist and a clear completion standard.
- Recovery guidance now tells users what to inspect first, when a `config_load` / Windows setup screen is a configuration issue, and when the explicit Windows compatibility retry is appropriate.
- Feature guidance explains local history continuity, model discovery, direct API versus compatibility gateway, plugins/data tools, and safe updates.
- The API model catalog and `model_catalog_json` behavior remain documented in the feature stage.
- Added matching Simplified Chinese and English translations, responsive stage-tab styling, and default-first-stage behavior whenever the tutorial opens.

## Preserved behavior

- The 1.9.9 official-to-API authentication isolation fix remains included.
- The 1.9.8 reserved `model_providers.openai` cleanup remains included.
- Account credentials, official snapshots, local projects, SQLite indexes, and rollout history remain local and protected.
- Windows sandbox settings and the explicit compatibility retry remain documented and unchanged.

## Documentation and verification

- Updated both READMEs, the in-app Chinese/English guide, release metadata, documentation checks, regression assertions, and release notes together.
- The 本地日志 remains the recovery source of truth; graceful shutdown failures are contained and reported instead of leaving the guide without a next action.
- `npm run check:docs` and the full automated test suite must pass before publication.
