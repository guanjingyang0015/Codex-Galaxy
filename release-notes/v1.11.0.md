# Codex Galaxy 1.11.0

## API audit and public ranking

- Added local API audit for saved API profiles and temporary Base URL/API Key/model input.
- Audit checks `/models`, Responses protocol, model listing, reasoning efforts, latency, usage shape, and a deterministic canary.
- Added a 100-point compatibility score with conforming, inconclusive, and suspicious assessments. Black-box results never claim official upstream authenticity.
- Added an optional public ranking service that stores only redacted aggregate metrics; API keys, prompts, outputs, OAuth, and chat history are rejected/not stored.
- Added homepage links, overall/recent sorting, rate limiting, and an isolated ranking service deployment target on the Tencent server.
- Removed the legacy relay recommendation panel and the project continuation panel from the main Galaxy page while preserving account/API management and local history data.

## Safety and deployment

- Public service runs separately from existing Tencent projects and does not touch NAS/Longma services.
- Public HTTPS is served through the isolated Cloudflare Tunnel `codex-galaxy-relay-rank` to the Tencent loopback service. The `api.vx314490015.cn` hostname remains the canonical client endpoint; the `workers.dev` Worker is an additional edge proxy.
- The original direct-origin Nginx/Origin CA path remains isolated as a fallback and is not required for the public route.
- Windows sandbox settings and the explicit compatibility retry remain unchanged and isolated.

## Verification

- The redacted 本地日志 remains the recovery source of truth; graceful shutdown failures are contained with a safe fallback.
- The model catalog and `model_catalog_json` metadata remain preserved when the relay declares them.
- Documentation consistency, full tests, syntax checks, offline audit, and local ranking-server tests pass before publication.
