# Codex Galaxy 1.9.6

## 文档与发布内容同步

- 本版本补齐中英文 README、软件内中英文使用教程、贡献指南、安全说明和发布说明。
- 发布门禁增加文档同步回归检查：当前版本必须同时出现在 `package.json`、`package-lock.json`、README、应用内教程、静态页面、发布记录和对应发布说明中。
- 以后每次版本更新都必须同步更新所有受影响的用户说明、操作规则、恢复说明、测试和安装包；文档检查未通过时不得发布。

## 1.9.5 功能说明同步

- 账号切换只会阻止确有近期未完成回复的情况，不会仅凭崩溃遗留的 `inProgress` 标记拦截。
- 重启后会合并本机 rollout 文件和 `thread_history` SQLite 中的用户/助手记录，线程详情不再只显示短尾部。
- 不要删除 `config.toml`、`~/.codex` 或 `~/.codex-galaxy` 来处理切换和历史问题。

## 发布边界

- API Key、OAuth、完整聊天记录和生产配置不会写入文档、日志、测试结果或 Git。
- Windows 安装包未签名，macOS 安装包由 GitHub Actions 构建验证。
- 只有测试、构建、GitHub Actions、公开 Release、标签目标和安装包资产全部验证通过后，版本才算正式发布。
