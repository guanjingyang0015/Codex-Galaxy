# Codex Galaxy 2.2.4

- 修复从 DeepSeek V4 Pro 切回官方 GPT 时，DeepSeek 推理历史中的 provider-local `content` 数组被重放到官方 Responses API，触发 `input[n].content array_above_max_length` 400 错误的问题。
- 官方切换现在会只清理不兼容的推理 `content` 和无效 provider 加密状态；合法官方 `rs...` 推理 ID、摘要和加密状态继续保留，并支持压缩历史中的同类记录。切换前后的会话文件仍可从备份精确恢复。
- DeepSeek V4 Pro 的模型目录回退显示低、中、高三档推理强度，不再误显示为只有两档；不擅自给该模型增加上游未声明的 `xhigh`。
- 首页和 OpenAI 状态详情页新增 90 天彩色健康度时间线：绿色正常、黄色性能下降、橙色部分中断、红色重大中断、蓝色维护中。每个每日色块都支持鼠标悬停查看日期、事件名称和公开原因。
- 时间线使用 OpenAI 官方公开状态摘要与事件流；事件流暂时不可用时，当前状态仍可正常显示，时间线会明确标为暂不可用。
- 本次发布继续保留 gracefulTerminate 的 catch 兜底、本地日志、model_catalog_json、Windows sandbox 和模型目录兼容性检查。
- README、应用内中英文教程、文档和回归测试已同步更新。
