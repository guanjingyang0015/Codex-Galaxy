# Codex Galaxy 1.13.0

## Background queue and layout

- Removed the bulk-audit button. Every saved-profile or temporary audit can be added immediately without waiting for earlier audits.
- Galaxy runs up to three independent audits concurrently and queues additional jobs, showing each job's status and progress.
- Reworked profile cards so long endpoint, model, status text, and action buttons wrap instead of being clipped.

## Ranking history and model views

- The default ranking is an all-model overall board; users can switch to any model observed in ranking history.
- For each site, the ranking score is the highest test score from the last 7 days. If there is no other test in that window, the current/latest score is used.
- Added the network-wide and per-site 90-day highest score with excellent, good, usable, inconclusive, and high-risk labels.
- Ranking rows show protocol, model identity, capability, stability, and latency component scores.

## Common non-GPT models

- GPT and o-series models keep the reasoning-effort probes.
- DeepSeek, Gemini, Claude-compatible Responses relays, and other non-GPT model IDs use three deterministic consistency probes without unsupported GPT reasoning parameters.
- Model identity remains evidence from `/models` and response metadata and can be falsified by a relay; the score does not prove official upstream origin.

## Existing scoring

- Model identity: 40 points.
- Model catalog and Responses protocol: 25 points.
- Reasoning or deterministic capability probes: 15 points.
- Stability: 10 points.
- Latency: 10 points.
- Critical model mismatch cap: 49 points.

## Safety and verification

- API keys remain in Electron `safeStorage`; only bounded redacted metrics reach the ranking service.
- The Cloudflare Tunnel, Worker, Tencent loopback service, account switching, Windows sandbox, and `model_catalog_json` boundaries remain unchanged.
- The redacted 本地日志 remains the recovery source of truth, and existing `gracefulTerminate(...).catch(...)` shutdown containment remains unchanged.
- README documentation, Chinese/English UI guidance, server migration, tests, and installers are updated together.
