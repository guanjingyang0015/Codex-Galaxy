# Codex Galaxy 3.2.0

## 本机项目继续入口

本版本同步更新 README 与应用内文档。

- 新增顶部“本地项目”窗口，显示 Codex 本机线程库，支持按标题/路径搜索、按项目筛选、刷新本机索引、查看线程详情，以及选择官方/API 账号继续。
- OpenAI Codex 仓库已有相同的自定义 API provider 项目列表问题报告（issue #31627）。此时官方项目可能从 Codex Desktop 侧栏隐藏，但本地数据库和会话文件仍保留；切回官方账号后，原生列表应恢复。此窗口提供本机继续入口。
- 此功能只读取 Galaxy 维护的本机项目库，不清理、迁移或上传线程与账号数据。
- 同步更新 README 和中英文使用教程；本地日志、`gracefulTerminate` + `catch`、`model_catalog_json` 和 Windows sandbox 兼容能力继续有效。
