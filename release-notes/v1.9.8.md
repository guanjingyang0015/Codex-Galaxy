# Codex Galaxy 1.9.8

## Official switch config-load repair

- Fixed API → official switching on current Codex builds: Galaxy no longer writes the reserved built-in provider as `[model_providers.openai]`.
- Older official snapshots that contain the stale provider override are detected and rewritten automatically before Codex starts; users no longer need to delete `config.toml`.
- The misleading Windows setup screen caused by this `config_load` failure is avoided. The explicit `unelevated` compatibility retry remains available only for a genuine machine-level elevated sandbox failure.

## Preserved behavior

- API and official switching continue to preserve the same local Codex Home, project list, SQLite indexes, and rollout history.
- API model discovery still supports `model_catalog_json`, including exact GPT IDs with additional selectable variants.
- Switch failures continue to roll back live credentials and provider metadata, and the local `本地日志` / `Log` file records only redacted diagnostic information with UTC and local time.

## Documentation and verification

- Updated both READMEs, the in-app Chinese/English guide, release metadata, and the release checklist together.
- `npm run check:docs` and the full automated test suite must pass before publication.
