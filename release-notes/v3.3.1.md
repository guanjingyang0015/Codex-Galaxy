# Codex Galaxy 3.3.1

## 项目范围说明

本版本同步更新中英文项目文档与应用内教程。

- 明确 Plus 与 Pro 是不同的 Codex 登录身份，本机项目登记可能按账号分别保存；项目列表差异不是 Plus/Pro 套餐等级造成的。
- Galaxy 的本地项目入口读取同一台电脑的 `state_5.sqlite` 项目目录登记，因此 Plus、Pro 或 API 配置均可浏览这些本机目录；可按项目根目录和 SQLite `project_id` 关联本机聊天，并从活动 session 文件恢复当前账号/provider 索引未列出的聊天。
- 线程继续仍使用已选账号自己的登录状态；本地目录共享不复制 OAuth、API Key 或账号会话。
- 同步更新 README 与中英文应用内教程；本地日志、`gracefulTerminate` + `catch`、`model_catalog_json` 和 Windows sandbox 兼容能力继续有效。
