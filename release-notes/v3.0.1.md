# Codex Galaxy 3.0.1

- 首页状态区改为单行紧凑布局：账号、登录模式、本地网关、Codex 状态与 OpenAI 健康度摘要并排显示，减少状态区撑高造成的空白，让账号管理和 API 检测/排名获得更多展示高度。
- 标题行增加简短功能提示，保留当前账号信息；健康度、CODEX HOME、作者邮箱和发布记录继续集中在状态区右侧。
- OpenAI 健康度色块悬停/键盘聚焦时显示时间、状态、事件和原因；简体中文界面会把状态、原因和组件用途转换为中文提示。
- 健康度常驻项目下拉框显示中文用途、英文原名和动态说明：GPT 网页版选 ChatGPT，Codex 网页版选 Codex Web，桌面版选 Codex in ChatGPT Desktop，接口调用选 Codex API。
- 教程新增健康度时间线和组件选择说明，解释颜色含义、悬停查看原因以及 GPT/Codex 对应选项。
- 健康度轮询改为前台每 5 分钟一次，窗口隐藏时暂停；请求增加并发复用，避免重复网络请求和渲染带来的资源压力。
- 保留 3.0.0 的 24 小时/每小时健康度数据、DeepSeek V4 Pro → 官方 GPT 历史兼容修复、低/中/高模型目录和安全更新能力。
- 本次发布继续保留 gracefulTerminate 的 catch 兜底、本地日志、model_catalog_json、Windows sandbox 和模型目录兼容性检查。
- README、应用内中英文教程、文档和回归测试已同步更新。
