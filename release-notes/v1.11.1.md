# Codex Galaxy 1.11.1

## Background API audit repair

- Saved API accounts now start an audit immediately from their encrypted local profile. Users no longer re-enter the platform name, Base URL, API key, or model.
- Removed the “Submit redacted result to public ranking” checkbox. Successful audits submit only redacted compatibility metrics automatically; API keys, prompts, outputs, OAuth, and chat history are never uploaded.
- Audits run as a background main-process task instead of locking the whole Galaxy interface. Closing the main window during a running audit hides Galaxy to the tray instead of interrupting the task.
- Added stage progress, a live remaining-time estimate, native completion/failure notifications, and an in-app result dialog.
- Normal audits usually take about 20–60 seconds. The displayed upper estimate is about 68 seconds when `/models` or reasoning probes reach their timeout.

## Compatibility boundaries

- The ranking endpoint, dedicated Cloudflare Tunnel, Worker, and Tencent loopback service are unchanged.
- Windows sandbox behavior and the explicit compatibility retry are unchanged.
- The existing `model_catalog_json` behavior and relay-declared model metadata remain unchanged.
- The redacted local log remains the recovery source of truth, and the existing `gracefulTerminate(...).catch(...)` safety boundary is unchanged.

## Verification

- Updated README documentation, the Chinese/English in-app text, regression tests, release metadata, and installers together.
- Documentation consistency, full tests, syntax checks, offline production audit, packaged-content inspection, and public endpoint smoke checks must pass before publication.
