# Codex Galaxy 3.1.2

## 修复与改进

本版本同步更新 README 与应用内文档，保持安装说明一致。

- 修复 macOS DMG 发布流程：Intel 与 Apple Silicon 分别使用对应原生 runner 构建，并在发布前校验应用签名和 CPU 架构。
- macOS 应用使用 ad hoc 签名，减少 Gatekeeper 将未签名应用误报为“文件损坏”的情况。首次下载仍可能需要 Finder 右键“打开”；公开包未使用 Apple Developer ID 证书公证。
- 继续保留本地日志、`gracefulTerminate` + `catch`、`model_catalog_json` 和 Windows sandbox 兼容能力。
- 本版本不新增复检队列，也不收集、保存或上传 API Key。
