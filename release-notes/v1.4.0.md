# Codex Galaxy 1.4.0

本版本新增客户端更新提醒和三平台正式构建流程。

## 新功能

- Galaxy 启动时自动检查 GitHub 最新正式版本，并每 6 小时重新检查一次。
- 顶部新增明显的更新按钮，也可随时手动检查。
- Windows 发现新版本后，可一键下载官方 Release 中精确匹配的 x64 安装包；下载完成前会核对固定仓库地址和 SHA-256，校验失败会删除文件且不会启动安装。
- Windows 启动安装前会提醒先完成正在生成的 API 对话；覆盖升级保留本地账号配置和聊天记录。
- macOS 因当前安装包未使用 Apple Developer 证书签名，更新按钮只会打开固定的 GitHub 最新版页面，不在应用内下载、挂载或启动 DMG。
- GitHub Actions 分别使用原生 Intel 与 Apple Silicon runner 构建 macOS x64/arm64，并为 Windows 和 macOS 附件生成独立 SHA-256 文件。

## macOS 安装提示

请在最新版页面按设备选择：

- Intel Mac：`Codex-Galaxy-1.4.0-macOS-x64.dmg`
- Apple Silicon（M 系列）：`Codex-Galaxy-1.4.0-macOS-arm64.dmg`

当前 macOS 包未签名、未公证，系统可能显示未知开发者提示。Galaxy 不会绕过 Gatekeeper。由于没有实体 Mac，本版本只声明 GitHub 原生 macOS runner 的自动测试、构建和包结构核验通过，不声明真机长期运行或交互已人工验收。

## Windows 安装提示

- 文件：`Codex-Galaxy-1.4.0-Windows-x64.exe`
- 当前安装包未签名，Windows SmartScreen 可能提示未知发布者。
- 若 Codex 正通过 Galaxy 的本地 API 网关生成回复，请先等待当前回复完成，再点击更新。

# English

This release adds in-app update notifications and a verified three-platform release pipeline.

## Highlights

- Galaxy checks the latest stable GitHub release at startup and every six hours.
- A visible top action allows a manual update check at any time.
- On Windows, one click downloads the exact x64 installer from the trusted GitHub Release, verifies its SHA-256, and launches setup only after verification succeeds.
- On macOS, the current builds are unsigned. The update action therefore opens the fixed official latest-release page and never downloads, mounts, or launches a DMG inside the app.
- GitHub Actions builds macOS x64 and arm64 on native Intel and Apple Silicon runners and publishes SHA-256 files for every installer.

The macOS builds are unsigned and not notarized. Automated GitHub macOS builds and package checks do not replace real-device validation.
