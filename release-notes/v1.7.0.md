# Codex Galaxy 1.7.0

## 连接稳定性与安全退出

- API Responses 流式回复增加 SSE 空闲保活，减少长时间无输出时 Codex 误判连接断开并反复重连。
- 流式响应补充 `no-cache` 与禁止代理缓冲标记；上游真正断流或 503 时仍会如实提示，不会伪装成成功。
- Galaxy 退出前会等待当前本地 API 请求完成，并把网关移交给独立后台服务；退出 Galaxy 不会关闭 Codex Desktop、app-server、CLI，也不会清除官方/API 登录状态。
- 下次启动 Galaxy 会安全接管后台网关；官方模式不启动网关。若当前回复仍在进行，Galaxy 会提示等待完成后再退出，避免主动中断。

Windows x64、macOS Intel x64、macOS Apple Silicon arm64 继续由 GitHub Actions 构建；当前安装包未签名。
