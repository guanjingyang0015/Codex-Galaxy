# Codex Galaxy 2.0.0

2.0.0 首页直接显示完整 API 排名，保留模型筛选和刷新，移除排名弹窗入口、最近排名参考、顶部当前模型和重复的 API 检测按钮。所有账号可用卡片 ↑ / ↓ 手动排序，顺序自动保存，编辑后不变。切换被未结束任务阻止时，弹窗列出聊天标题、项目和最近活动时间，标注定时任务并可直接打开聊天；无法读取任务时仍阻止切换。教程已补充官方 A → 官方 B：两个账号分别登录和捕获，再选择目标账号切换。

2.0.0 shows the complete API ranking directly on the homepage with model filtering and refresh. The ranking dialog, recent preview, current-model status, and duplicate audit button are removed. Use ↑ / ↓ on any account card to persist account order; editing preserves it. When unfinished tasks block switching, the dialog lists chat titles, projects and last activity, labels scheduled tasks, and can open the specific chat. Unreadable activity still blocks switching. The guide now covers official A → official B after separately signing in and capturing each account.

- Includes the unpublished 1.13.1 reasoning-ID repair: API → official history removes incompatible optional reasoning IDs, inspects compacted replacement history, and invalidates old compatibility caches. Exact backups and rollback preserve history.
- Documentation and Chinese/English tutorials updated together. Existing Windows sandbox, model_catalog_json, gracefulTerminate(...).catch(...) shutdown handling, and 本地日志 recovery remain in place.
- User credentials stay in the encrypted vault. Reordering touches profile metadata only. Task titles/project paths stay local; the open action is restricted to tasks in the current confirmation.
