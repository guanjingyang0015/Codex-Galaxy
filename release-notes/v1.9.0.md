# Codex Galaxy 1.9.0

## 多中转站管理

- 可在桌面中添加、编辑和删除多个中转 API 配置。
- 每个中转配置独立保存 Base URL、模型 ID、运行方式和加密 API Key。
- API Key 支持安全替换和清除；当前正在使用的配置不能被删除或清除 Key。
- 增加只访问标准 `/models` 接口的连接测试，并显示可读的认证、路径、服务器和网络错误。
- API 直连模式仍是默认方式，不依赖 Galaxy 常驻运行；兼容网关模式继续作为可选项。
- 保留官方账号、API 账号之间的项目和聊天记录同步，以及跨模型继续能力。

## 安全与兼容

- API Key 只保存在本机加密 vault 中，不进入公开配置、项目记录、测试结果或发布文件。
- Base URL 只接受 HTTP/HTTPS 地址，并拒绝内嵌用户名或密码，避免凭据被明文保存。
- 旧版 API 配置自动迁移到纯 API 模式。
- 连接测试只保存状态、HTTP 状态码和时间，不保存中转站响应正文。

Windows x64、macOS Intel x64、macOS Apple Silicon arm64 安装包由 GitHub Actions 构建；当前安装包未签名。
