# Codex Galaxy 1.9.2

## 多中转站管理

- 延续 1.9.1 的多中转站管理、API Key 加密保存和官方/API 项目记录同步能力。

## 官方账号切换稳定性

- 如果 Codex 正在生成回复或无法确认回复已经写入本地，Galaxy 会阻止账号切换，避免未落盘的回复丢失；空闲状态下先请求 Codex 正常关闭，只有进程未退出时才使用强制结束。
- 清理 API/官方切换中 `sandbox_mode = "danger-full-access"` 与 Windows `elevated` 沙盒组合缺少兼容标记的问题，写入 Codex 支持的 `windows.sandbox_private_desktop = false`，保留原有全访问设置和 `elevated` 沙盒级别，不静默降级为 `unelevated`。

## 聊天记录连续性

- Galaxy 固定保存上一版 GitHub 发布记录（提交、标签、Actions 和 Release 地址），切换账号或重新打开后仍可查看，不依赖当前聊天窗口是否保留上一条回复。
- 切换失败回滚不再覆盖最新的本地项目库；会根据恢复后的真实 Codex 数据重新同步。
- 即使 Codex 的 `has_user_event` 投影暂时为 0，只要历史库能证明存在真实用户消息，Galaxy 仍会保留该线程。
- 临时空扫描不会清空已有项目库，因此切换失败或 Codex 正在重建索引时不会丢失已显示的回复和发布记录。

## 验证

- 增加未完成回复拦截、优雅关闭、Windows 沙盒冲突修复、扩展路径读取和切换失败后项目库保留回归测试。
- Windows x64 安装包由 electron-builder 构建；当前安装包未签名。
