# Codex Galaxy 1.9.7

## 发布记录修复

- 修正当前安装版本的发布记录，使已发布版本显示真实的 GitHub 提交和 Actions 信息，而不是“本地版本/Actions 未知”。
- 保留 1.9.6 的文档同步门禁：每次版本更新都必须同步更新中英文 README、软件内中英文使用教程、发布说明、发布记录、测试和安装包。
- `npm run check:docs` 和 `npm run stamp:release` 继续作为 CI 发布前检查；文档或版本内容不同步时，构建流程会在安装包任务前失败。

## 兼容性与安全

- 延续 1.9.5 的切换误报修复和完整线程历史恢复。
- 不删除 `config.toml`、本机 Codex 数据、SQLite 数据库或聊天文件。
- API Key、OAuth、完整聊天记录和生产配置不会写入文档、日志、测试结果或 Git。

## 发布边界

- 只有测试、文档检查、构建、GitHub Actions、公开 Release、标签目标和安装包资产全部验证通过后，版本才算正式发布。
- Windows 安装包未签名；macOS 安装包由 GitHub Actions 构建验证。
