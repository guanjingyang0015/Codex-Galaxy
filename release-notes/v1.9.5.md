# Codex Galaxy 1.9.5

## 切换保护误报修复

- 不再仅凭历史遗留的 `inProgress` 数据库标记阻止账号切换。
- 仍会保护最近活动的回复；超过安全窗口且没有后续终态记录的崩溃遗留标记不会被当作当前任务。
- 同一线程已经出现后续完成、失败或中断回合时，旧的未完成标记不会再次触发拦截。

## 聊天记录恢复

- Galaxy 启动时会先同步一次本机 Codex 项目库，避免重启后继续显示旧缓存。
- 线程详情不再被 200 条消息上限截断。
- 如果桌面历史数据库已经写入、但 rollout 文件尚未完全刷新，详情页会合并两份本地记录并去重。

## 发布记录

- 发布记录会以当前安装版本为首项，避免安装新版本后仍显示旧版本。
- 当前版本的 GitHub Release 入口始终使用对应的 `v1.9.5` 标签。

## 验证边界

- 不删除 `config.toml`、本地线程、SQLite 数据库或聊天文件。
- 不读取或记录 API Key、OAuth、聊天正文或生产配置。
- Windows 安装包未签名；macOS 安装包仍以 CI 构建验证为主。
