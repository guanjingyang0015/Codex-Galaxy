# Codex Galaxy 3.2.2

## 本地项目绝对恢复

- 切换到 API provider 时，如果当前索引暂时看不到官方线程，只要本机项目目录或会话文件仍存在，Galaxy 就保留该项目记录，不会因 provider 过滤从本地项目库移除。
- 顶部“本地项目”入口可直接搜索、查看和继续这些项目；切回官方账号后也会重新同步原生线程索引。
- 新增隔离回归测试覆盖官方 → API → 官方切换和 provider 索引缺口。
- 同步更新 README 与中英文应用内文档；本地日志、`gracefulTerminate` + `catch`、`model_catalog_json` 和 Windows sandbox 兼容能力继续有效。
