# Codex Galaxy 3.3.0

## 跨账号本机项目目录

本版本同步更新 README 与应用内文档。

- 本地项目窗口只读 `state_5.sqlite` 的 `projects` 与 `project_roots`，显示本机登记的项目名称和目录，不依赖当前账号的 Codex Desktop renderer 项目列表，也支持 API 模式查看。Plus/Pro 不同登录账号的目录登记可能互相不可见，这是账号作用域，不是套餐权限差异。
- 切换/启动时若当前 provider 的线程索引遗漏本地会话，Galaxy 会按文件流读取 `sessions/` 的 session 元数据，只补充索引中缺失且未明确归档/标记为子代理的线程。
- 项目卡片按会话 `cwd` 匹配目录根路径，可筛选该目录下的本地会话并用现有账号继续。
- 不读取或修改账号专属 renderer 全局状态，不复制 OAuth/API 凭据，不改写 Codex 安装目录。
- 同步更新 README 与中英文应用内教程；本地日志、`gracefulTerminate` + `catch`、`model_catalog_json` 和 Windows sandbox 兼容能力继续有效。
