# Codex Galaxy 1.9.1

## 多中转站管理

- 延续 1.9.0 的多中转站管理、API Key 加密保存和官方/API 项目记录同步能力。

## 修复高频自动优化对话

- 移除 API 模型目录对未知模型的伪造 `128000` 上下文窗口、`max_context_window` 和 `effective_context_window_percent`；上下文相关字段只有中转站明确提供时才写入目录，不再由一个字段推导另外两个阈值。
- 切换官方账号或 API 账号时清理旧版本遗留的全局 `model_context_window`、`model_auto_compact_token_limit` 和作用域覆盖，避免旧模型阈值继续控制新模型。
- 重新选择当前 API 配置时自动识别并替换 1.9.0 生成的人工 128K 模型目录，不需要先切换到其他账号。
- 清理旧模型目录中可能导致 Codex `config_load` 失败的无效推理档位；切换到官方账号时不再继承 API 的模型目录。
- 保留 Codex 对真实上下文达到模型限制时的正常压缩行为；本修复针对 Galaxy 人为缩小窗口和遗留阈值造成的过早、高频优化。

## 官方账号与 Windows

- 官方账号切换继续使用原有 `config.toml`、`auth.json` 和本地线程记录的原子备份/恢复流程，不再需要删除配置文件。
- 不强制关闭 Codex 的 Windows 沙盒；如果机器本身阻止一次性提升权限，仍可按 Codex 官方 Windows 沙盒设置选择 `unelevated` 作为系统级回退，而不会影响 Galaxy 的账号和聊天切换。

## 验证

- 增加目录、API/官方配置切换和旧版目录升级回归测试。
- Windows x64 安装包由本地 electron-builder 构建；当前安装包未签名。
