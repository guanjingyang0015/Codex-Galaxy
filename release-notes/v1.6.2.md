# Codex Galaxy 1.6.2

## API provider 配置清理

- 修复 API 切换后 Codex 同时显示旧 `custom` provider 和当前 `galaxy` provider 的问题。
- API 模式现在只写入当前实际使用的 provider 定义，保留 MCP、沙盒等无关配置。
- 切回官方模式时也会清理旧的 API provider 表，避免下次启动继续显示过期入口。

## 流式连接错误提示

- 修复上游 Responses 流式响应中途断开时，网关直接销毁本地连接、导致 Codex 显示 `error decoding response body` 的问题。
- 网关现在返回明确的 SSE 错误事件并正常收尾，提示用户重试或检查中转站/网络。
- 不会把 API Key、请求正文或上游私密地址写入错误提示。

## CLI 版本选择

- 修复 Windows 同时存在旧版固定入口和新版版本目录副本时，Galaxy 仍优先启动旧版 CLI 的问题。
- Galaxy 会探测候选 CLI 的实际版本并选择最高版本；用户显式指定的自定义路径仍然优先。若 `CODEX_CLI_PATH` 只是指向 Windows 安装器留下的旧 `bin\codex.exe` 兼容入口，则会自动改用版本目录中的新版副本。

Windows x64、macOS Intel x64、macOS Apple Silicon arm64 继续由 GitHub Actions 构建；当前安装包未签名。
