# Codex Galaxy 1.6.1

## API 配置自动修复

- 修复 API 模式下 `model_provider = "galaxy"` 仍在、但对应 `[model_providers.galaxy]` 定义丢失时被误判为正常的问题。
- Galaxy 启动、重新选择当前 API 和“在 Codex 中继续”前都会验证 provider 定义、Responses 协议和本地网关地址。
- 发现可恢复的残缺配置后，Galaxy 会自动补齐并二次校验；校验失败时阻止 Codex 使用错误配置启动。
- 修复只更新账号路由相关字段，保留 MCP、沙盒和其他用户自定义 TOML 配置。

## 旧会话安全边界

- `rollout does not start with session metadata` 仍由 1.6.0 加入的旧会话健康诊断处理。
- Galaxy 只使用会话文件中真实存在的元数据或与线程匹配的可信备份；不会生成虚假的 `session_meta`。
- Windows x64、macOS Intel x64、macOS Apple Silicon arm64 继续由 GitHub Actions 构建；当前安装包未签名。
