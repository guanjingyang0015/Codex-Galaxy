# Codex Galaxy 1.9.3

## 多中转站管理

- 延续 1.9.2 的多中转站管理、API Key 加密保存和 GitHub 发布记录显示能力。

## 官方账号启动顺序

- 修复 1.9.2 写入 `windows.sandbox_private_desktop = false` 后仍反复访问 `C:\Users\Default`、导致 Windows 设置页卡住的问题；切换时会无条件清理这个旧字段。
- 官方账号切换现在先恢复官方配置并打开 Codex；只有用户确认已经进入正常使用页面后，Galaxy 才会关闭 Codex、同步本地线程兼容信息并继续原项目。
- 如果官方登录过程中刷新了令牌，Galaxy 会在 Codex 正常关闭后安全更新该官方账号快照，确保下次切换仍使用最新登录状态。
- 如果官方 Codex 仍停留在 Windows 设置或 `config_load` 页面，可以取消本次切换；Galaxy 会恢复切换前的账号和本地聊天，不会要求删除 `config.toml`。

## 聊天窗口连续性

- 普通账号切换会自动续接切换前最新的本地线程，不再只打开空白首页。
- 使用正式 Codex 线程启动方式恢复原线程，避免切换后当前聊天窗口看起来像新会话。
- 1.9.1 和 1.9.2 的 GitHub 提交、标签、Actions 和 Release 信息会持续显示在 Galaxy 中。

## 验证

- 增加官方启动前置、线程续接和 1.9.2 配置回退回归测试。
- Windows x64 安装包由 electron-builder 构建；当前安装包未签名。
