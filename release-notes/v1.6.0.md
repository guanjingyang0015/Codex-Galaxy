# Codex Galaxy 1.6.0

## 旧会话安全恢复

- 针对新版 Codex 报告 `thread-store internal error`、提示 rollout 缺少开头 `session_meta` 的旧任务，新增会话健康诊断。
- 诊断发现可安全整理时，先创建原文件的字节级备份，再仅移动真实匹配的会话元数据；不会凭空生成元数据。
- 缺少元数据时，只接受与线程和文件路径匹配的可信 Galaxy 历史备份；无法验证来源时保持阻止状态。
- Codex Desktop、Codex CLI 或其后台写入进程运行时禁止修复，并在替换前后检查文件是否被改动。
- 修复后保留恢复备份和审计记录，用户可在详情窗口确认健康状态后继续任务。

## 兼容性与发布

- API、官方账号切换、插件、本地数据和更新功能保持不变。
- Windows x64、macOS Intel x64、macOS Apple Silicon arm64 均由 GitHub Actions 构建；当前安装包未签名，系统可能显示安全提示。
