# Codex Galaxy 1.8.0

## API 运行解耦与上下文开销优化

- API 账号默认使用 API 直连模式，直接连接用户填写的服务商 Base URL；完成切换后 Codex 不再依赖 Galaxy 主窗口或后台进程。
- 对不兼容直连 Responses API 的服务商，仍可选择兼容网关模式；该模式会明确提示需要 Galaxy 网关运行，并支持安全移交到独立后台。
- 已填写模型 ID 的 API 直连账号跳过 `/models` 探测，减少切换等待和额外网络请求。
- 精简模型目录中的重复 instructions 注入，避免每轮请求携带两份相同的身份与边界说明，降低上下文膨胀和不必要的自动压缩。
- 增加 runtimeMode 配置迁移与回归测试，旧 API 配置会安全迁移到 API 直连模式。

真实达到模型上下文上限时，Codex 仍可能正常压缩上下文；本版本解决的是 Galaxy 额外造成的重复注入、网关转发和模型探测开销。

Windows x64、macOS Intel x64、macOS Apple Silicon arm64 继续由 GitHub Actions 构建；当前安装包未签名。
