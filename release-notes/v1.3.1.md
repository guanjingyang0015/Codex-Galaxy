# Codex Galaxy 1.3.1

## 中文

这是一次上下文连续性与界面缺陷修复版本。

- 修复自定义 API 模型切换后的上下文优先级：压缩摘要、交接记录和旧计划只作为背景，最新用户消息定义当前请求。
- 只有用户明确要求“继续”时才恢复旧任务；简单问答不会再因旧摘要擅自调用工具或修改文件。
- 删除 Galaxy 主窗口顶部操作区重复的 `Codex Galaxy x.x.x` 胶囊，保留左上角简洁版本号和 Windows 外部 Codex 窗口右上角标识。
- 清除异常答复误写入的 `2.0.0`、重复中转站按钮和无功能依据的消息着色代码。
- 许可证元数据统一为 MIT。

Windows x64 安装包：

- 文件：`Codex-Galaxy-1.3.1-Windows-x64.exe`
- 大小：`104400218` bytes
- SHA-256：`1BDB230AA181EC6BD743FECC7F15E218B92EF8242D8D198F1C57577836E62A7B`

可直接覆盖 0.1.0 或更高版本安装，账号配置和本地聊天不会被安装器主动删除。使用 API 时请先完成正在运行的 Codex 任务，因为安装程序会关闭 Galaxy 和本地网关。

当前安装包未签名，Windows SmartScreen 可能显示“未知发布者”。

## English

This release fixes context continuity after custom API model switches and removes a redundant main-window badge.

- Compaction summaries, handoff notes, and unfinished plans are now background only; the latest user message defines the current request.
- Older work resumes only when the user explicitly asks to continue it.
- Simple questions no longer trigger tools or file edits merely because an older summary mentions unfinished work.
- The redundant `Codex Galaxy x.x.x` pill was removed from the Galaxy action bar. The compact header version and the Windows external Codex marker remain.
- Accidental `2.0.0` metadata, duplicate relay buttons, and unsupported message-coloring code were removed.
- Package metadata now consistently declares the MIT License.

Windows x64 installer:

- File: `Codex-Galaxy-1.3.1-Windows-x64.exe`
- Size: `104400218` bytes
- SHA-256: `1BDB230AA181EC6BD743FECC7F15E218B92EF8242D8D198F1C57577836E62A7B`

Install directly over version 0.1.0 or later. Galaxy profiles and local Codex chats are retained. Finish active API-backed Codex work before upgrading because setup closes Galaxy and its local gateway.

The installer is unsigned and may trigger a Windows SmartScreen warning.
