# Codex Galaxy 1.7.1

## 聊天流中断可见性修复

- Responses SSE 流现在会识别 `response.completed`、`response.incomplete`、`response.failed`、`response.cancelled`、`error` 和 `[DONE]` 等终止信号。
- 上游在终止信号前意外断开时，Galaxy 会向 Codex 返回明确的“回复可能不完整，请重试”错误，不再把异常 EOF 静默当成正常完成。
- 保持正常 SSE 内容、失败事件和取消事件原样转发；完成事件之后的连接收尾不会被误报为流式错误。
- 增加了 Fetch/Node 两种传输、CRLF、分片 UTF-8 和异常断流回归测试。

Windows x64、macOS Intel x64、macOS Apple Silicon arm64 继续由 GitHub Actions 构建；当前安装包未签名。
