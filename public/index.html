SAFE SWITCHING GUIDE

安全切换教程

项目和完整聊天记录始终保存在本机同一个 Codex Home 中。Codex Galaxy 切换的是登录凭据、API provider 和继续项目所需的本地索引，不会把聊天上传到其他账号。当前版本为 v1.9.6。
1

保存第一个官方账号

  1. 先在 Codex Desktop 中正常登录官方账号，并等待项目列表加载完成。
  2. 回到 Galaxy，点击账号区右上角“+”，添加一个“Codex 官方账号”。名称可随时修改。
  3. 点击该账号右侧“捕获”。看到保存成功后，这个官方登录状态才可在以后恢复。
2

添加一个或多个中转 API

  1. 点击“+”，类型选择“中转 API”。
  2. 填写自定义名称、Base URL 和 API Key。模型 ID 可以留空，切换时 Galaxy 会读取中转站的标准模型列表，优先复用该账号最近成功的模型，否则选择列表中的第一个模型并显示结果。
  3. 每个 API 账号都使用独立纯 API 登录，不需要官方账号，也可以在多个 API 之间直接切换。
3

一键安全切换

  1. 点选目标账号，确认下方显示的名称和模型正确。
  2. 如果 Codex 正在生成近期回复，Galaxy 会阻止切换，等回复完成后再操作；如果只是空闲打开，会先请求正常关闭并等待本地写入。崩溃遗留的旧 inProgress 标记不会单独阻止切换。
  3. 确认继续后，Galaxy 会保存最新本地项目记录，再切换目标凭据和 provider。API 直连模式直接使用填写的 Base URL；只有选择“兼容网关”时才会启动本地网关。
  4. 兼容性检查只处理新增或变化的历史；点击“在 Codex 中继续”打开具体线程时优先检查该线程，不会每次重复扫描整个 Codex Home。
  5. 等待进度到 100%。Galaxy 会再次刷新目标账号的项目列表，然后重新打开 Codex。
4

继续处理原项目

  1. Codex 重新打开后，从原来的项目或任务进入即可看到此前的聊天内容。
  2. “查看详情”只在 Galaxy 中查看本机线程信息，不切换账号；“在 Codex 中继续”会使用当前选中的账号完成必要的切换/同步并恢复该项目。
  3. 重启后 Galaxy 会从 rollout 文件和本机 thread_history SQLite 合并尚未完全落盘的用户/助手消息并去重；线程详情不会只保留最近一小段记录。
  4. 历史消息不会因 GPT、DeepSeek 或其他模型之间的切换而改写；新回复使用当前目标模型。
  5. 如果任务详情提示含加密推理状态，只表示另一家 provider 可能无法复用原 provider 的隐藏推理片段，不会删除聊天或项目文件。
5

API 模式按需使用网关

API 直连模式下，Codex 直接连接你填写的 Base URL，切换完成后可以完全退出 Galaxy，不影响 Codex 的运行、账号状态或聊天记录。只有选择“兼容网关”时才需要 Galaxy 网关；关闭主窗口会缩到托盘，退出时 Galaxy 会先安全移交网关到独立后台。

6

刷新项目与清理数据

  1. “刷新项目”只重建显示列表，不删除原始数据；Galaxy 每次进程启动时也会先完成一次本地项目库同步。
  2. 需要彻底删除时，点击顶部“清理数据”，勾选“已归档/已删除项目”。Galaxy 会先创建可恢复备份，再清理对应的本地记录。
  3. 清理不会删除任何用户项目源代码目录。
7

异常恢复

  1. 切换失败时先看进度区提示。新版会自动恢复切换前的凭据、provider、网关和当前账号标记。
  2. Galaxy 只允许一个程序实例执行切换；上次异常退出遗留的同步锁会在确认原进程已不存在后自动回收。
  3. 如果 Codex 提示 DNS、TLS、系统代理、上游内存过载或认证失败，先确认中转站及电脑网络正常；Galaxy 不会在错误信息中显示 API Key 或请求正文。
  4. 若自动恢复未完全成功，不要删除 config.toml，也不要手动删除 ~/.codex 或 ~/.codex-galaxy；保留脱敏错误截图并提交反馈。
8

升级 Codex Galaxy

  1. Galaxy 1.9.6 启动后会自动检查 GitHub 最新正式版本，也可点击顶部更新按钮手动检查。
  2. Windows 发现新版本后可一键下载；Galaxy 会先核对官方 Release 地址和 SHA-256，再启动安装程序。若正在使用 API，请先完成 Codex 当前任务，因为安装会关闭 Galaxy 及其本地网关。
  3. macOS 当前安装包没有 Apple Developer 签名，更新按钮只会打开项目的 GitHub 最新版页面。请按 Intel x64 或 Apple Silicon arm64 选择 DMG，并遵循系统安全提示，不要绕过 Gatekeeper。
  4. 直接覆盖安装即可，不需要手动卸载旧版；账号配置和本地记录会保留。
  5. 以后每次版本更新都会同步更新版本号、README、中英文教程、发布说明、测试和安装包；文档一致性检查未通过时不会发布。
  6. 如需额外保险，可先备份 .codex-galaxy，不要上传或提交到 Git。
9

插件、图片和自动化清理

  1. 顶部“插件”可以安装本地插件目录或添加插件市场。远程公共目录需要切换到已捕获的官方 ChatGPT 账号；没有官方账号时仍可使用不依赖远程目录的独立本地插件。
  2. 图片/文件能力取决于中转站与模型的实际支持，Galaxy 会原样转发请求内容。
  3. 自动化清理只处理完成/归档的运行历史，执行前备份，默认关闭；它与项目清理彼此独立。
